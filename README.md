# TypeFlow

Adaptive typing practice website built with PHP, CSS and vanilla JavaScript.

## Phase 1

- Dark interface
- Adaptive practice text
- 15, 30 and 60 second sessions
- Live WPM, accuracy and error count
- Virtual keyboard
- Browser localStorage for basic statistics and settings

## Run locally with XAMPP

1. Install XAMPP.
2. Clone this repository into `C:\\xampp\\htdocs\\typeflow`.
3. Start Apache from the XAMPP Control Panel.
4. Open http://localhost/typeflow/ in your browser.

MySQL is not required for Phase 1. Progress is stored in the browser on the device being used.

## Development

The `development` branch is used for ongoing changes. Merge into `main` when ready to publish.
